# Лісова Мрія

Сайт із земельними ділянками та інтерактивним генпланом: https://lisova-mriya.top/

Ціни, телефон і перелік вільних ділянок міняються в блоці `CONFIG` на початку скрипта в `index.html`.
На хостинг сайт потрапляє через cPanel → Git Version Control → Update from Remote → Deploy HEAD Commit (файл `.cpanel.yml`).
